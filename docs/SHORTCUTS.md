# Clice Keyboard Shortcuts Reference

## Global Shortcuts
| Key | Action |
| --- | --- |
| `Ctrl+K` | Open **Spotlight** (instant search for apps, plugins & recent files) |
| `Ctrl+B` | Focus Left Sidebar (`↑`/`↓` + `Enter` to switch apps) |
| `Ctrl+\` | Collapse / Expand Sidebar (full-width focus mode) |
| `Ctrl+T` | Cycle Color Theme (saved automatically) |
| `F1` – `F9` | Home, Sheets, Docs, Slides, Files, DevTools, Calc, Notes, Calendar |
| `F10` | Open Help & Shortcuts overlay |
| `Ctrl+P` | Textual Command Palette |
| `Ctrl+Q` | Quit Clice |

## Clice Sheets (Excel)
- `↑` `↓` `←` `→` — Navigate cells
- `Enter` / `F2` — Edit selected cell in Formula Bar
- `Esc` — Return focus to grid
- `Delete` — Clear selected cell
- `Ctrl+O` / `Ctrl+S` — Open File Picker / Save
- `Ctrl+R` / `Ctrl+L` — Add Row / Add Column

## Clice Docs (Word)
- `Ctrl+O` / `Ctrl+S` — Open File Picker / Save (`.md`, `.docx`, `.txt`)
- `Ctrl+F` — Toggle Find & Replace bar
- `Ctrl+I` / `Ctrl+K` — Insert Italic / Code Block
- `Ctrl+1` / `Ctrl+2` — Insert Heading 1 / Heading 2

## Clice Slides (PowerPoint)
- `Ctrl+O` / `Ctrl+S` — Open File Picker / Save (`.pptx`, `.md`, `.json`)
- `Ctrl+M` — Add New Slide
- `Alt+P` — Launch Full-Screen Present Mode (`←`/`→`/`Space` navigate, `Esc` exit)
- `Alt+↑` / `Alt+↓` — Switch Slides

## Clice Files
- `↑`/`↓` + `Enter` — Browse folders or open file in matching Clice app
- `←` / `Backspace` — Go up one directory (`..`)
- `H` — Go to Home directory (`~`)
- `M` — Create directory (`mkdir`)
- `N` — Create file (`touch`)
- `Delete` — Delete selected file/folder
- `C` — CD & Exit (works with `clice-cd`)

## Developer Tools
- **SQLite Studio**: `Ctrl+Enter` Run SQL • `Ctrl+O` Open `.db`
- **HTTP Client**: `Ctrl+Enter` Send Request
- **Plugins & Marketplace**: `Enter` Download & Install (Marketplace) or Launch (Installed) • `R` Reload
